# ⛏️ CubeCraft Pro 

**Бесплатная браузерная 2D-песочница в стиле Minecraft**  
Выживание · Крафт · Боссы · Рыбалка · Чистый HTML5/JS

![CubeCraft Pro](screenshot.png)

## 🎮 О игре

**CubeCraft Pro** — это полноценная браузерная игра-песочница, написанная **на чистом HTML, CSS и JavaScript** без единой внешней библиотеки. Работает **офлайн** — достаточно открыть `index.html` в любом современном браузере.

Часть серии бесплатных социальных офлайн-проектов **[Anti-AI Shield](https://ancf-hue.github.io/)**.

## ✨ Возможности

### 🌍 Мир
- 🗺️ **20×20 тайлов** с процедурной генерацией
- 🏞️ **5 биомов**: Лес, Пустыня, Снег, Пустошь, Озеро
- 🌄 **Цикл день/ночь** с динамическим освещением
- 🌧️ **Динамическая погода** (дождь)
- 🕳️ **Пещеры** с затемнением
- 📦 **Сундуки** со случайным лутом

### ⚔️ Боевая система
- 🧟 **3 типа мобов**: Зомби, Скелеты, Пауки
- 👹 **Босс «Лорд Теней»** (30 HP) — появляется на 5-ю ночь
- 🏹 **Лук и стрелы** с прицелом по курсору
- ⚔️ **Ближний бой**: меч, топор, кулаки
- ✨ **Точило** — улучшение оружия (+1 урон)

### 🛠️ Крафт (18 предметов)
- 🪓 Топор, ⛏️ Кирка, ⚔️ Меч, 🏹 Лук
- 🎣 Удочка, 🛶 Лодка, 🧪 Зелья
- 🛡️ Кожаная и каменная броня (-30%/-60% урона)
- 🔥 Факелы (отпугивают мобов)
- 🛏️ Кровать (точка возрождения)
- ➹ Стрелы, 🍲 Готовка еды

### 🎣 Активности
- 🎣 **Рыбалка** — ловите рыбу стоя в воде
- 🛶 **Лодка** — плавайте по озёрам
- 🏹 **Стрельба из лука** — клавиша R или Ctrl+клик
- 📦 **Поиск сундуков** — бонусные ресурсы

### 🏆 Прогрессия
- ⭐ **10 уровней** с увеличением HP
- 🏆 **10 достижений** (Охотник, Рыбак, Убийца босса и др.)
- 💾 **Автосохранение** в localStorage
- 🔄 **Точка возрождения** у кровати

### 🎨 Визуал и звук
- 🔊 **15 звуковых эффектов** через Web Audio API (без файлов!)
- 🌟 Анимированные частицы (урон, лут, уровни)
- 🗺️ Мини-карта в реальном времени
- 🌃 Динамическое освещение от факелов
- 🌧️ Анимация дождя и волн на воде

## 🎮 Управление

| Клавиша | Действие |
|---|---|
| ⬆️⬇️⬅️➡️ / WASD / ФЫВА | Движение |
| ЛКМ | Добыча ресурса |
| ПКМ / Shift+ЛКМ | Быстрое разрушение |
| Space | Атака ближнего боя |
| R / К | Стрельба из лука (в курсор) |
| X / Ч | Рыбалка (стоя в воде) |
| B / И | Сесть/выйти из лодки |
| E / У | Съесть еду |
| F / А | Поставить факел |
| ESC | Пауза / Меню |

## 🛠️ Технологии

- **HTML5** — структура
- **CSS3** — glassmorphism, 3D-кнопки, анимации
- **JavaScript (ES6)** — вся игровая логика
- **Canvas API** — отрисовка мира
- **Web Audio API** — процедурные звуки
- **localStorage** — сохранение прогресса

**Ноль зависимостей. Ноль библиотек. Ноль фреймворков.**
